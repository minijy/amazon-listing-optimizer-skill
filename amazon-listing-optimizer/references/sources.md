## Research conclusions encoded in this skill

- Relevance and conversion are related but distinct; diagnose funnel stage before rewriting.
- Exact product facts and expectation setting outrank persuasive flourish.
- Keyword repetition is not a substitute for relevance; reserve backend terms for incremental coverage.
- Image sequence should answer purchase questions and prove claims.
- Reviews and returns reveal language and objections, but do not substantiate product claims.
- Category rules override generalized length recommendations.
- Performance improvements require measurement; no wording pattern guarantees rank or sales.

No external Skill content was copied. Public Skill searches produced mostly generic prompt wrappers without auditable policy sourcing, so the implementation uses Amazon’s current first-party guidance and an original workflow.
